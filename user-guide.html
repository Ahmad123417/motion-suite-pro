Instalasi & Alur Aktivasi Lisensi

Petunjuk lengkap pemasangan installer, penyalinan Machine ID, dan formulir aktivasi lisensi otomatis via web.

1
Buka & Pasang Aplikasi
Jalankan Motion Suite Pro Setup v1.0.5.exe sampai aplikasi terbuka. Jika muncul peringatan Windows SmartScreen, klik teks "More info" lalu pilih "Run anyway".
2
Salin Machine ID Laptop Anda
Di dalam aplikasi, perhatikan panel "Status Lisensi" pada bilah kiri atas. Salin deretan kode unik Machine ID perangkat Anda.
3
Isi Formulir Aktivasi Lisensi Web
Buka formulir aktivasi resmi di browser: https://motionsuite-act.duckdns.org/form/c1dc1a25-386b-4780-9e60-454b6201969e. Masukkan Nomor Invoice Lynk.id dan Machine ID perangkat Anda.
* Catatan Pengiriman: Lisensi resmi otomatis dikirimkan ke email pembeli setelah formulir dikirim. Harap periksa folder Inbox maupun folder Spam / Junk email Anda.
4
Validasi Kode Lisensi RSA-SHA256 di Aplikasi
Buka email Anda dan salin kode lisensi resmi yang diterima (format tanda tangan digital RSA-SHA256: payload.signature). Tempelkan seluruh teks ke kolom Lisensi di aplikasi, lalu klik "Validasi". Status aplikasi otomatis berubah menjadi "Aktif" dengan indikator hijau sesuai paket lisensi Anda (1 Hari Trial, 3 Hari, 7 Hari Mingguan, 30 Hari Bulanan, atau Lifetime Access).

Integrasi Mandiri Google Gemini API (100% Gratis)

Panduan langkah demi langkah mendapatkan dan menghubungkan Google Gemini API Key resmi tanpa biaya langganan bulanan.

Mengapa Motion Suite Pro Memerlukan Gemini API?
Motion Suite Pro menerapkan model BYOK (Bring Your Own Key). Gemini digunakan secara eksklusif sebagai Creative Coding Engine untuk menyusun kode animasi programatis TypeScript/React bertenaga High-Performance Vector Motion Engine berkecepatan tinggi. Anda TIDAK dikenakan biaya langganan karena Google menyediakan kuota Free-Tier harian yang sangat leluasa.

4 Langkah Cepat Menghubungkan Gemini API Key:

1
Buka Portal Resmi Google AI Studio
Buka browser (Chrome/Edge/Firefox) dan kunjungi: https://aistudio.google.com. Masuk (Sign in) menggunakan akun Google pribadi atau kerja Anda.
2
Buat API Key Baru (Create API Key)
Di panel navigasi sebelah kiri, klik menu "Get API key", lalu klik tombol biru "Create API key". Pada jendela pop-up, pilih opsi "Create API key in new project" (atau pilih project Google Cloud yang tersedia).
3
Salin Kunci Rahasia Anda
Google akan membuat sebuah string token unik yang diawali dengan kode AIzaSy.... Klik tombol "Copy" pada baris kunci tersebut untuk menyalinnya ke papan klip komputer Anda.
4
Tempel & Simpan di Motion Suite Pro
Kembali ke aplikasi Motion Suite Pro. Cari panel "Gemini API Key" di sidebar kiri, tempelkan kunci ke kolom input, lalu klik tombol hijau "Simpan". Indikator akan berubah menjadi hijau bertuliskan "Tersimpan".
Kapasitas Kuota Google AI Studio (Free Tier) Gratis Permanen

Batas Permintaan Per Menit (RPM):

Hingga 15 RPM (Cukup untuk pembuatan puluhan animasi per jam).

Batas Permintaan Harian (RPD):

1.500 RPD (Sangat besar untuk penggunaan intensif harian).

Panduan Prompt Engine, Resolusi 4K & Format Ekspor

Memahami arsitektur rendering berbasis kode matematis dan pemilihan format ProRes 4444 Alpha vs MP4.

Arsitektur Prompt-to-Code: Mengapa Berbeda? Zero Hallucination

❌ AI Generatif Video Biasa (Difusi)

Menghasilkan video buram/noise, teks acak tidak terbaca, bentuk melengkung tak terkendali, resolusi terbatas, dan tidak bisa diedit parametrik.

✅ Motion Suite Pro (Prompt-to-Code)

Prompt diterjemahkan menjadi kode programatis React/TypeScript. Teks tajam presisi piksel, kurva matematis, alpha transparan murni, dan dapat di-tweak kapan saja!

Pemilihan Format Ekspor Video:

Apple ProRes 4444 (.MOV) Alpha Murni

Standar broadcast & motion design untuk transparansi murni (tanpa background hitam).

  • Mendukung Transparansi Penuh (Alpha 10-bit) pixel format yuva444p10le.
  • Wajib untuk compositing di Premiere Pro, After Effects, DaVinci Resolve, FCP.
  • Sangat bernilai tinggi untuk penjualan aset video di microstock (Envato, Motion Array).
MPEG-4 H.264 (.MP4) Universal Standard

Format video solid dengan efisiensi kompresi tinggi untuk distribusi langsung ke media sosial.

  • Ukuran file ringkas dengan kualitas visual prima.
  • Kompatibilitas 100% pada semua player, smartphone, YouTube, IG, TikTok.
  • Proses encoding cepat dan stabil untuk peninjauan cepat klien.

Pemecahan Masalah Cepat (Troubleshooting)

Solusi langsung untuk kendala umum saat inisialisasi awal, pemanggilan API, dan proses rendering.

1
Inisialisasi Kanvas Awal
Gejala: Layar gelap atau "Port 10871 Offline" 3–5 detik awal saat compiler dan visual canvas internal memuat modul TypeScript.
Solusi: Biarkan hingga server siap. Jika belum sinkron, klik "Sync Canvas" pada bilah atas kanvas.
2
Galat Kuota API (HTTP 429)
Gejala: Kuota tercapai karena batas frekuensi (RPM) Google AI Studio terlampaui.
Solusi: Tunggu 30–60 detik hingga kuota reset. Atau buat project baru di aistudio.google.com dan simpan kunci baru.
3
Galat Kode Komposisi
Gejala: Layar merah dengan galat sintaks TypeScript saat mengedit manual.
Solusi: Klik tombol "⚡ Auto-Fix Error". AI Self-Healing Engine menganalisis stack trace dan memperbaikinya dalam 2–3 detik.
4
Lokasi File Hasil Render
Folder Default:
C:\Users\<NamaUser>\Downloads\Motion Studio Exports
Folder dapat diubah sebelum render atau klik "Buka Folder" selesai render.
5
Peringatan "Manipulasi Jam Sistem Terdeteksi" (CLOCK_DESYNC)
Gejala: Jendela peringatan jam sistem dimundurkan dan fitur render terkunci sementara karena jam komputer berada di belakang stempel waktu aman aplikasi.
Solusi Cepat 1-Klik: Klik tombol "🔄 Sinkronkan Waktu via Internet (1-Klik)" langsung pada jendela peringatan aplikasi. Sistem mencocokkan waktu dengan server resmi (Google / Cloudflare) dan memulihkan akses seketika!
