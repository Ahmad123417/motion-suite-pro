Integrasi Mandiri Google Gemini API (100% Gratis)

Panduan langkah demi langkah mendapatkan dan menghubungkan Google Gemini API Key resmi tanpa biaya langganan bulanan.

Mengapa Motion Suite Pro Memerlukan Gemini API?
Motion Suite Pro menerapkan model BYOK (Bring Your Own Key). Gemini digunakan secara eksklusif sebagai Creative Coding Engine untuk menyusun kode animasi programatis TypeScript/React Remotion berkecepatan tinggi. Anda TIDAK dikenakan biaya langganan karena Google menyediakan kuota Free-Tier harian yang sangat leluasa.

4 Langkah Cepat Menghubungkan Gemini API Key:

1
Buka Portal Resmi Google AI Studio
Buka browser (Chrome/Edge/Firefox) dan kunjungi: https://aistudio.google.com. Masuk (Sign in) menggunakan akun Google pribadi atau kerja Anda.
2
Buat API Key Baru (Create API Key)
Di panel navigasi sebelah kiri, klik menu "Get API key", lalu klik tombol biru "Create API key". Pada jendela pop-up, pilih opsi "Create API key in new project" (atau pilih project Google Cloud yang tersedia).
3
Salin Kunci Rahasia Anda
Google akan membuat sebuah string token unik yang diawali dengan kode AIzaSy.... Klik tombol "Copy" pada baris kunci tersebut untuk menyalinnya ke papan klip komputer Anda.
4
Tempel & Simpan di Motion Suite Pro
Kembali ke aplikasi Motion Suite Pro. Cari panel "Gemini API Key" di sidebar kiri, tempelkan kunci ke kolom input, lalu klik tombol hijau "Simpan". Indikator akan berubah menjadi hijau bertuliskan "Tersimpan".
Kapasitas Kuota Google AI Studio (Free Tier) Gratis Permanen

Batas Permintaan Per Menit (RPM):

Hingga 15 RPM (Cukup untuk pembuatan puluhan animasi per jam).

Batas Permintaan Harian (RPD):

1.500 RPD (Sangat besar untuk penggunaan intensif harian).

Panduan Prompt Engine, Resolusi 4K & Format Ekspor

Memahami arsitektur rendering berbasis kode matematis dan pemilihan format ProRes 4444 Alpha vs MP4.

Arsitektur Prompt-to-Code: Mengapa Berbeda? Zero Hallucination

❌ Model AI Generatif Video Biasa (Difusi)

Menghasilkan video buram/noise, teks acak tidak terbaca, bentuk melengkung tak terkendali, resolusi terbatas, dan tidak bisa diedit ulang secara parametrik.

✅ Motion Suite Pro (Prompt-to-Code)

Prompt diterjemahkan menjadi kode programatis React/TypeScript. Teks tajam presisi piksel, kurva animasi matematis, transparan asli, dan dapat di-tweak kapan saja!

Pemilihan Format Ekspor Video:

Apple ProRes 4444 (.MOV) Alpha Channel Murni

Standar tertinggi industri broadcast dan motion design untuk transparansi murni (tanpa latar belakang hitam).

  • Mendukung Transparansi Penuh (Alpha 10-bit) dengan pixel format yuva444p10le.
  • Wajib untuk compositing di Premiere Pro, After Effects, DaVinci Resolve, & Final Cut Pro.
  • Sangat bernilai tinggi untuk penjualan aset video di pasar microstock (Envato, Pond5, Motion Array).
MPEG-4 H.264 (.MP4) Universal Standard

Format video solid dengan efisiensi kompresi tinggi untuk distribusi langsung ke media sosial dan presentasi.

  • Ukuran file ringkas dengan kualitas visual prima.
  • Kompatibilitas 100% pada semua player, smartphone, YouTube, Instagram, dan TikTok.
  • Proses encoding cepat dan stabil untuk peninjauan cepat klien.

Pemecahan Masalah Cepat (Troubleshooting)

Solusi langsung untuk kendala umum saat inisialisasi awal, pemanggilan API, dan proses rendering.

1
Inisialisasi Kanvas Butuh Beberapa Detik Saat Pertama Dibuka
Gejala: Kanvas preview menampilkan layar gelap atau indikator "Port 10871 Offline / Initializing" selama 3–5 detik awal.
Penyebab: Remotion compiler dan background bundling service sedang melakukan inisialisasi modul TypeScript secara lokal di latar belakang.
Solusi: Biarkan aplikasi berjalan beberapa detik hingga server lokal siap. Jika dalam 8 detik kanvas belum tersinkronisasi, cukup klik tombol "Sync Canvas" pada bilah atas kanvas untuk memicu auto-reload.
2
Galat Kuota API Key (HTTP 429: Resource Exhausted)
Gejala: Muncul pesan galat permintaan gagal atau kuota API tercapai saat melakukan generate animasi baru.
Penyebab: Batas kecepatan (RPM / Request Per Minute) kuota gratis dari Google AI Studio telah terlampaui karena beberapa prompt dikirimkan terlalu cepat.
Solusi: Tunggu 30–60 detik hingga Google mereset jendela kuota per-menit. Atau, buat API Key baru dengan membuat project baru di aistudio.google.com lalu simpan kunci baru tersebut di sidebar aplikasi.
3
Galat Kode Komposisi Saat Mengedit Manual
Gejala: Kanvas menampilkan layar merah dengan keterangan galat sintaks TypeScript.
Solusi: Anda tidak perlu memperbaiki kode secara manual! Cukup klik tombol "⚡ Auto-Fix Error" pada bilah aksi. AI Self-Healing Engine akan menganalisis tumpukan galat (stack trace) dan memperbaikinya dalam 2–3 detik secara otomatis.
4
Di Mana Lokasi File Video Hasil Render Disimpan?
Folder penyimpanan default berada di:
C:\Users\<NamaUser>\Downloads\Motion Studio Exports
Anda dapat mengubah folder penyimpanan kapan saja sebelum memulai render atau mengklik tombol "Buka Folder" setelah proses render selesai.
