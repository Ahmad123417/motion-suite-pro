PENTING: HARAP BACA SEMUA LANGKAH DI BAWAH INI SEBELUM MEMASANG APLIKASI
================================================================================

1. BUKA & PASANG APLIKASI:
   - Jalankan "Motion Suite Pro Setup v1.0.5.exe" sampai aplikasi terbuka.
   - Jika muncul peringatan Windows SmartScreen, klik "More info" lalu pilih "Run anyway".

2. SALIN MACHINE ID:
   - Di dalam aplikasi, lihat panel kiri atas pada bagian "Status Lisensi".
   - Salin deretan kode "Machine ID" perangkat Anda (atau klik tombol salin 📋).

3. KLAIM KODE LISENSI KE WHATSAPP ADMIN:
   - Kirim chat ke WA Admin: 085161180423 dengan format:
     * Bukti Pembayaran / Invoice Lynk.id
     * Machine ID laptop Anda
     * Pilihan Paket: 1 Hari (Trial), 3 Hari, 7 Hari (Mingguan), 30 Hari (Bulanan), atau Lifetime
   - Catatan Antrean: Lisensi diproses berurutan dari chat paling bawah (yang masuk lebih awal).
     Mohon TIDAK melakukan spam atau chat berulang-ulang, karena chat baru akan menaikkan posisi Anda ke paling atas dan menunda antrean aktivasi.

4. AKTIVASI LISENSI:
   - Setelah menerima kode lisensi dari admin/email, tempelkan kodenya ke kolom Lisensi di aplikasi, lalu klik "Validasi".
   - Format Kunci Lisensi Baru: Kunci lisensi berbentuk deretan karakter digital terenkripsi RSA-SHA256 (format: payload.signature). Pastikan menyalin SELURUH teks kunci tanpa spasi tambahan.
   - Status akan langsung berubah menjadi "Aktif" dengan indikator hijau sesuai paket yang Anda beli:
     * 1 Hari (Trial 24 Jam)
     * 3 Hari (Trial Ekstensi)
     * 7 Hari (Akses Mingguan)
     * 30 Hari (Akses Bulanan)
     * Lifetime Access (Aktif Selamanya Permanen)

5. PASANG GEMINI API KEY (GRATIS):
   - Buka aistudio.google.com di browser, login dengan akun Google.
   - Klik "Get API key" -> "Create API key in new project" -> Salin kode token AIzaSy...
   - Tempel ke kolom "Gemini API Key" di aplikasi, lalu klik "Simpan".

6. SELESAI:
   - Motion Suite Pro siap digunakan untuk membuat animasi motion graphic 4K!

PANDUAN TROUBLESHOOTING & PENANGANAN KENDALA LISENSI:
================================================================================

A. JIKA MUNCUL PERINGATAN "JAM SISTEM DIMUNDURKAN / CLOCK_DESYNC":
   - Gejala: Fitur render terkunci sementara dan muncul jendela "Manipulasi Jam Sistem Terdeteksi".
   - Penyebab: Tanggal/jam sistem Windows Anda berada di belakang stempel waktu terakhir aplikasi dijalankan (Anti-Clock Rollback Protection).
   - Solusi 1-Klik (Rekomendasi):
     1. Klik tombol "🔄 Sinkronkan Waktu via Internet (1-Klik)" yang ada langsung di jendela peringatan aplikasi.
     2. Sistem akan memverifikasi waktu resmi dari server internet dunia (Google / Cloudflare).
     3. Akses aplikasi akan terbuka kembali seketika tanpa perlu restart!
   - Solusi Manual Windows (Jika offline):
     1. Buka Windows Settings -> Time & Language -> Date & Time.
     2. Pastikan "Set time automatically" aktif.
     3. Klik tombol "Sync now" pada bagian Synchronize your clock.
     4. Buka kembali aplikasi Motion Suite Pro.

B. JIKA MUNCUL PERINGATAN "MASA BERLAKU TELAH BERAKHIR (EXPIRED)":
   - Gejala: Muncul jendela peringatan "Masa Berlaku Lisensi Telah Berakhir".
   - Solusi:
     1. Salin kode Machine ID yang tampil pada jendela peringatan.
     2. Hubungi WA Admin: 085161180423 untuk perpanjangan masa aktif (Top-up).
     3. Masukkan Kunci Lisensi baru yang Anda terima ke kolom yang tersedia, lalu klik "Aktifkan Lisensi Baru".
